Postgraduate Diploma Project

2026

Machine Learning Techniques for Optimizing DCO-OFDM in LiFi Communication

Supervisor: Prof. Dr. Md. Rubaiyat Hossain Mondal — IICT, BUET, Dhaka, Bangladesh

Built a MATLAB-simulated DCO-OFDM LiFi dataset of 27,720 samples spanning modulation orders (M = 4–4096) and subcarrier configurations (N = 64–4096). Benchmarked 42 regression models via LazyPredict, then developed Polynomial Regression, MLP, and HistGradientBoostingRegressor models individually — establishing HGBRegressor as the strongest predictor using only two statistical features, cutting input feature overhead by 60% versus existing literature.

R² = 0.9958 · RMSE = 0.0575 · p = 0.0067 (Friedman) · 5-fold CV σR² = 0.0001 · cross-dataset R² = 0.8114 · 0.11% loss on 30% corrupted data

ELITE Research Lab LLC
